# sources — the reading the guides are built on

Drop things here for the **librarian** to read:

- **PDFs** of articles, handbooks or book chapters you are allowed to keep. Just copy the file in.
- **Links**: write or paste web addresses into any text file here (`links.md` is the one that came with this
  example). One address per line, with a few words saying what it is.
- **Your own notes** about how you like to run interviews, as `.txt` or `.md` files.

Then open the librarian (see the Start-here page) and say: *"Read what is new in sources and update the methods base."*
It reads only what is new or changed, and writes `methods-base/METHODS-BASE.md`: the rules for good questions, each with
the source it came from and a short quoted line. It never makes up a reference. If it cannot open a link or a PDF it says so.

**Copyright:** no source text is bundled beyond short quotes (each under 40 words, with its link and the licence the page
states); the quoted words stay their authors'. Keep your own PDFs on
your own computer; do not publish this folder if it holds files you do not have the right to share.
